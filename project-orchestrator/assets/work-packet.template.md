## Blocker protocol

遇到以下情况不要擅自改目标，停止在可恢复状态并返回主编排 agent：
- acceptance criteria 本身不合理；
- 需要改变公共数据/评测协议；
- 与其他 issue 发生 scope 冲突；
- 需要破坏性 Git / 数据操作；
- 发现会推翻当前项目路线的重要证据。

## Completion report

返回：
1. 做了什么；
2. 实际验证结果；
3. commit / PR 或 no-code result；
4. 关键产物路径；
5. 未解决问题；
6. 是否满足全部 acceptance criteria。
